# Sales Dashboard Project

##  Steps Followed

1. **Imported the CSV file** into Power BI / Tableau.
2. **Converted `Order Date`** field to **Month-Year** format for consistent time-series analysis.
3. **Created the following visuals**:
   -  **Line Chart**: Sales over Months
   -  **Bar Chart**: Sales by Region
   -  **Pie Chart**: Sales by Category
4. **Added a slicer** for **Region** and **Category** to allow interactive filtering.
5. **Applied color formatting** to highlight top-performing areas (e.g., darker shades for higher sales).
6. **Extracted key insights** based on the visual trends.


## Tools Used

- **Tableau**
- CSV as data source
- Basic data transformations (Date formatting, filtering)
